## 🔒 公信力说明

- 每场比赛保留原始信号行与赛果行（`daily/*/bets.json`、`daily/*/results.json` 的 `raw_line` 字段）
- 所有数据由私有脚本自动从邮箱同步，人工不干预
- Git 提交历史提供不可篡改的时间戳
- 投注本金固定 **100 元/场**，盈亏按 (`odds-1`) 计算；赢半 +50×(odds-1)，输半 -50
